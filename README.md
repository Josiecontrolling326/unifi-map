## 🗺️ About the Application

The unifi-map tool turns your complex network setup into simple visuals. It connects to your UniFi network controller to pull data about your devices. You can save these maps as SVG, PDF, or draw.io files. The output includes images of your actual Ubiquiti hardware. This makes it easy to document your home or office network without manual drawing.

## 🛠️ System Requirements

- Windows 10 or Windows 11
- At least 4GB of RAM
- An active network connection to your UniFi controller
- The Java Runtime Environment (JRE) installed on your system

## 🚀 Setting Up Your Map

1. Open the folder where you saved the file.
2. Double-click the unifi-map file to launch the program.
3. Windows might show a message asking for permission. Click Run to start the application.
4. Enter the address of your UniFi controller in the settings box. This is usually the IP address of your Cloud Key or server.
5. Provide your UniFi username and password. The program uses these credentials to talk to your network equipment.
6. Click the Connect button to begin the scan.

## 🎨 Creating Your Visuals

Once the program finds your devices, it displays a list on your screen. You can choose the format for your final output:

- SVG: Best for websites or high-quality scaling.
- PDF: Best for printing or sharing documents.
- draw.io: Best if you need to move or rename devices manually after the export.

Select your preferred format from the menu. Click the Generate button to save your file to your desktop.

## 🔧 Troubleshooting Common Issues

If the program fails to connect, check your network settings. Ensure your computer sits on the same network as your UniFi controller. Verify that your username and password provide read access to the network data. If you see an error about Java, install the current version of the Java Runtime Environment from the official website. Ensure your firewall does not block the application from sending data to your network controller.

## 📈 Frequently Asked Questions

**Does this software change my network settings?**
No. This tool only reads data from your controller. It does not send commands or update your equipment.

**Can I export specific parts of my network?**
Yes. You can select individual switches or access points before you click the generate button.

**Will the images look like my real devices?**
Yes. The software matches your device models to internal artwork files to provide a realistic look.

**Where does the software save my files?**
By default, the software saves your generated maps to your desktop. You can change this location in the settings menu.

**How do I update the software?**
Visit the download link again and replace the old file with the newer version. Your settings usually stay saved in a separate file, but keep a note of your controller address just in case.
